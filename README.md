
# CheeseSkript

This is a fork of [Skript](https://github.com/SkriptLang/Skript/) used for [@BlueCheeseDevelopment](https://github.com/BlueCheeseDevelopment). It contains minor patches and experimental syntax.

> **！Important**  
> CheeseSkript continues to follow all  
> coding conventions and guidelines setup  
> by the [upstream](https://github.com/SkriptLang/Skript/).
